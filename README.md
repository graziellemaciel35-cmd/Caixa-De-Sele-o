# Projeto Caixa de Seleção ☑️

## 📌 Sobre o projeto
Projeto simples de caixa de seleção (Checkbox) desenvolvido utilizando HTML e CSS, com foco em prática de formulários, estilização de inputs e interação visual.

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3

## 🎯 Objetivo
O objetivo deste projeto foi praticar:
- Estruturação de formulários
- Criação de caixas de seleção
- Estilização com CSS
- Organização de código
